# VICEPULSE

VICEPULSE is an independent tracker of community efforts to run Grand Theft Auto VI on PC. It covers gameplay, graphics, frame rate and stability through a public leaderboard, project history and a sourced news archive.

[Open VICEPULSE](https://axxcodes.github.io/VICEPULSE/) · [Read the latest news](https://axxcodes.github.io/VICEPULSE/news/) · [Follow AxxCodes on X](https://x.com/axxcodes)

## Gameplay readiness

| Benchmark | Evidence |
| --- | --- |
| Player control | Input moves a character in a rendered scene. |
| Graphics | Textures, lighting and shaders render correctly in the scenes tested. |
| Frame rate | The reported gameplay frame rate is measured against 30 FPS. |
| Sustained 30 FPS | A gameplay test holds 30 FPS over time. |
| Crash-free play | A timed Windows gameplay run is measured against 30 minutes. |

The headline percentage is a weighted score for the leading build. The graphics percentages are estimates based on the scenes available for review. Menu FPS stays outside the gameplay score. The countdown is an estimate for the crash-free benchmark and can change with new evidence.
