# Editorial policy

VICEPULSE uses dated public sources for project assessments, including maintainer updates, release notes, test logs and gameplay recordings. Attribution distinguishes first-hand testing, contributor claims and third-party coverage.

Player control requires input in a rendered scene. Graphics estimates reflect the scenes shown. Frame-rate measurements use live gameplay. Sustained FPS and crash-free play each need a timed test. A documented run identifies the build, hardware, time played and crash behavior.

Forks can be listed when they publish distinct changes and tests. Their entries credit upstream work and identify which build produced the results.

The public score history records assessments as evidence changes. [Corrections](https://github.com/AxxCodes/VICEPULSE/issues) are welcome.
