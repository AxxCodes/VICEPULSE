SeriesX Emulator and Port of the Americas repositories go offline

Confirmed by VICEPULSE · GitHub repository status

Both GitHub addresses now return 404. VIctory-NVIDIA still leads the active Race at 90%.

VICEPULSE checked the GitHub repositories for SeriesX Emulator and Port of the Americas on November 27. Both returned 404. The status confirms that those addresses are unavailable to the public. The reason is unknown.

VIctory-NVIDIA remains the active leader at 90%. Its README still reports mostly 26–30 rendered FPS in opening rooms on one RTX 5070 system. The published result covers the opening rooms, so the December 1–7 watch window remains low confidence.
