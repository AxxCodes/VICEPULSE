Leonida's Discord server disappears as the project moves to a new GitHub account

The 179,000-member server stopped resolving late on Monday. Members say Discord banned it; nobody has said why. Update: the GitHub repository has since been deleted too.

Leonida's Discord server went offline late on Monday. At 23:06 UTC its invite still led to a server of about 179,000 members, 74,000 of them online. Within a minute Discord answered that both the invite and the server were unknown. Members say Discord banned it. Neither Discord nor the Leonida team has said why, and from outside we can't tell a ban from a deletion.

At first the code was untouched. About an hour earlier the repository had moved from its creator's personal account to a new organization, ProjectLeonida, created at 22:08 UTC. Old links redirected, and issues were still being updated after the server went dark. Around the same time the maintainers closed thousands of open pull requests and issues, cutting the list from nearly 4,900 to about 200.

GitHub's public DMCA log shows no notice against the project. The disappearance follows other pressure on GTA VI communities: earlier this month the GTA 6 Mapping Project's Discord vanished without explanation, and in August Take-Two sought subpoenas against Discord to identify the leaker, which Discord said it hadn't been served.

Update, 23:47 UTC: the GitHub repository has since been deleted, and its creator says he has quit. See our follow-up.
