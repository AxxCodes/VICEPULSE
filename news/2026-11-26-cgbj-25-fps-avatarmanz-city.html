GTA VI PC tracker records a 25 FPS report for CGBJ

Confirmed by VICEPULSE · Linked footage and GitHub repository status

The CGBJ footage shows the boat mission. Its GitHub repository returns 404, while AvatarManz’s public AMD fork reports about 19 FPS in a city-street test.

PortWatch lists CGBJ, associated with codec-d’s cool_fox repository, at an average of 25 FPS on NVIDIA hardware. VICEPULSE reviewed the linked 55-second video. It shows the boat mission and its driving HUD. The clip does not establish the gameplay average or a sustained 30 FPS run.

The GitHub repository returned 404 when checked on November 26. The cause is unknown. We kept the result in the news and archived the leaderboard entry while the code is unavailable.

Separately, AvatarManz’s public Radeon fork reports about 19 FPS in a city-street scene, up from about 13–17 FPS in the same scene. The new trial used an RX 7900 XTX with ray tracing off and two experimental renderer options enabled. That is one hardware configuration and one scene. The leaderboard uses that published result and the countdown still tracks the evidence review for extended gameplay near 30 FPS.
