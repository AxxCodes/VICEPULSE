Leonida gets GTA VI's executable running, but nothing is on screen yet

Contributors' builds run the game's own code for minutes behind a blank window; posts in its Discord say it won't be playable today, but maybe tomorrow.

Hours after Cyberleek's executable appeared on Monday, Leonida's contributors began running it through the project's runtime and logging each attempt in a shared issue. On builds that stack about 25 unmerged pull requests, the retail executable now runs its own code for up to three minutes on Windows, Wine and Proton. It sets up the graphics device, gets through audio setup, builds tens of thousands of graphics pipelines and opens a window.

That window stays blank. The current wall is a console-only call on the game's command allocators that the PC layer doesn't answer, so frames never finish. None of the boot fixes are in Leonida's main branch yet, and contributors call merging them the bottleneck.

Posts in Leonida's Discord server told the same story. Soon after the drop, one said the game won't be playable today, "but maybe tomorrow". Later, another said it "almost boots", with a black screen and audio that cuts off. We can't check that timeline, and the repo still lists input, saves and streaming as not started.

Leonida isn't alone. XCL runs a retail game its notes identify by GTA VI's executable at 30 fps on a black screen, and TuxBox shows the same black window on Proton. All three now sit at our Exe runs stage, 25%. None has drawn a picture.
