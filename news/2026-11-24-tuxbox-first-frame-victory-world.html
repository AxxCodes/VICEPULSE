TuxBox draws GTA VI's first screen as VIctory edges into the world

Overnight, a Linux-first layer showed GTA VI's player-selection prompt, VIctory reported a title card inside the game world, and two smaller projects got GTA VI's code running.

Leonida's exit hasn't slowed the other GTA VI ports. TuxBox, a compatibility layer tested mostly on Linux through Proton, published a run record showing the game's player-selection prompt at 4K on an RTX 4070 Ti SUPER. It hasn't sent the game any input yet, so we count it as a first frame, not a menu. That takes TuxBox from 25% to 40%.

VIctory, level with XCL at the main menu, now says its runs reach the world. The first mission's title card renders, but the scene behind it stays dark at roughly one frame every one to two seconds, and the project warns that real GPUs can hang. That isn't playable, so VIctory stays at 55%.

PercyScarlett reports GTA VI running to a frame loop of black frames before the GPU hangs, and a new project, GTA6-BootTest, gets its exe through the same stage with stand-in DLLs. Both now sit at "Exe runs". As always, these are the projects' own reports; none has been reproduced independently.
