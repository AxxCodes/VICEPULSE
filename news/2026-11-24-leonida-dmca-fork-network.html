GitHub processes Take-Two’s takedown across Leonida’s fork network

GitHub says the notice was processed against a network of 3,007 repositories, including the original.

GitHub published a DMCA notice from Take-Two Interactive concerning the Leonida repository, an unofficial GTA VI PC effort. In an editorial note above the notice, GitHub says it processed the request against the entire network of 3,007 repositories.

Take-Two alleges copyright infringement and says Leonida relied on material from the leaked Xbox build. The public notice identifies Leonida and its fork network. The fxceless victory-fork repository was still publicly accessible when we checked.

VICEPULSE keeps Leonida visible as archived and records the published notice on its tracker entry.
